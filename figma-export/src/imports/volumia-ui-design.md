Design a premium desktop UI for an AI-powered architecture and 3D modeling app called VOLUMIA.

Style:
– Apple macOS aesthetic
– ultra-clean minimal layout
– translucent glass panels with very subtle blur
– rounded corners 8–12px
– calm architectural feel
– professional, timeless

Create BOTH Light Mode and Dark Mode versions.

LIGHT MODE:
– bone white background
– warm sand beige panels
– muted bronze accent highlights
– soft graphite text
– subtle shadows only

DARK MODE:
– deep graphite background (#1C1C1E style)
– translucent dark glass panels
– soft neutral gray text
– muted bronze accents for active tools
– avoid pure black
– high readability for long work sessions

Layout optimized for RTX workstation and dual monitors:
– large central 3D viewport (75% width)
– collapsible right properties panel (materials, lighting, XYZ transform)
– hidden left navigation panel appearing on hover
– minimal bottom tools bar
– floating panels that don’t block viewport

3D viewport visuals:
– HDR soft lighting
– subtle shadow plane
– minimal grid floor
– object centered at world origin
– controls hints: rotate left click, zoom scroll, move XYZ gizmo

Architecture tools:
– buttons: Generate 3D, Apply Texture, Import Reference Image, Export GLB
– asset library with furniture thumbnails
– project header with VOLUMIA logo
– notes panel hidden

Typography:
– Apple-style sans-serif (SF Pro style)
– calm hierarchy
– optimized readability for architects working long hours

Performance considerations:
– avoid heavy blur everywhere
– lightweight UI elements
– minimal animations
– clean layout to keep GPU free for rendering

Goal:
Interface similar to Apple Final Cut + Rhino + Autodesk Fusion,
for architects using RTX GPUs,
premium, calm, elegant, production-ready.

Avoid:
– neon colors
– gaming UI
– cluttered panels
– thick borders
– heavy gradients
