# VOLUMIA Typography

## Objective
Typography must feel precise, premium, and calm for professional architecture workflows.

## Primary UI Stack
- Aptos
- Segoe UI Variable Text
- Segoe UI
- sans-serif

## Rules
- Headings: medium/semibold with controlled tracking.
- Body: regular weight, high readability.
- Uppercase labels: compact sizes with increased letter spacing.
- Avoid decorative display fonts in core product UI.

## Suggested Scale
- Display: 26px / 1.2 / +0.20em tracking (brand hero only)
- H1: 24-30px / 1.2 / slight negative tracking
- H2: 16-20px / 1.25
- Body: 13-15px / 1.5
- Metadata / captions: 10-12px / uppercase when needed
